# leonf.me

Personal website for Leon S. Freyermuth.

## Stack

- Static HTML/CSS
- Times New Roman, black text on white, and blue underlined links
- Hosted on GitHub Pages

## Development

Open `index.html` in a browser, or run `python3 -m http.server 8000`.

## Previous design

The complete homepage as it existed before the plain redesign, including local edits, its stylesheet, favicon, and assets, is preserved in `archive/2026-09-05/`. Open its `index.html` to view it independently.

The original plain experiment remains in `previews/plain/`.

## Deployment

Pushes to `main` automatically deploy to https://leonf.me. Keep `CNAME` unchanged.
