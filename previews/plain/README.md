# Plain homepage experiment

Open `index.html` directly, or run `python3 -m http.server 8000` from the repository root and visit http://localhost:8000/previews/plain/.

This separate preview uses Times New Roman, black text on white, and blue underlined links. It removes the card, portrait, section labels, and selected-work list, while retaining the current introduction and background copy. The white background also stays white in dark mode.

The root homepage and stylesheet are unchanged. This preview has no analytics and requests that search engines not index it. It is local until committed and deployed; if included in a future GitHub Pages deployment, it will be accessible at `/previews/plain/`.
